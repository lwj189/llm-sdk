## 一、先跑三条命令（30 秒，看机器上的真实状态）

~~~bash
cd ~/桌面/sdk
git log --oneline -5            # 走到第几天：看最新 commit 的天数
git status -sb                  # 干净吗？main 和 origin/main 是不是同一个 sha
cmake --build build -j 2>&1 | grep -c "warning:" ; ctest --test-dir build --output-on-failure | tail -3
~~~

判读：

| 看到什么 | 说明 |
| --- | --- |
| 最新 commit 是 `docs:` / `chore:` 开头 | 只是收尾，代码进度看前一条 |
| `## main...origin/main` 没有 ahead/behind | 本地和 GitHub 同步（origin 走 ssh:443，见计划 §2 网络备注） |
| `warning:` 计数 0、`100% tests passed` | 验收第 1、2 条还立着 |
